# Задача 9. Проверка отсортированности

## Обозначения

`n` — количество элементов массива, `1 < n < 100000`.
Используется модель, в которой сравнение, присваивание, арифметическая операция над int или long и обращение к элементу массива занимают O(1). Чтение и вывод одного числа фиксированного диапазона учитываются как O(1). Время ожидания ввода человеком не учитывается. Фиксированные расходы JVM и ввода-вывода не меняют приведённые порядки роста.

O обозначает верхнюю асимптотическую оценку, Θ — точный порядок роста.

## Идея решения

Программа считывает массив и предполагает, что он отсортирован. Далее сравниваются соседние элементы. Если arr[i] < arr[i - 1], нарушено неубывание: флаг становится false, цикл завершается. Равные соседние значения допускаются. По итоговому флагу выводится YES или NO.

## Время проверки массива

Цикл начинается с i = 1. Каждая итерация проверяет одну соседнюю пару.

- Лучший случай: первая пара нарушает порядок. Выполняется одно сравнение — Θ(1).
- Худший случай: массив неубывающий или единственное нарушение находится в последней паре. Выполняется n − 1 сравнение — Θ(n).
- Если первое нарушение обнаружено на индексе i = p, проверено p соседних пар — Θ(p).

Средний случай зависит от распределения входных массивов; без заданного распределения отдельная средняя оценка для проверки не утверждается.

## Время всей программы

1. Создание и обнуление массива — O(n).
2. Чтение всех n элементов — Θ(n).
3. Инициализация флага — O(1).
4. Проверка порядка — от Θ(1) до Θ(n).
5. Формирование и вывод YES или NO — O(1).

До проверки программа всегда считывает весь массив. Поэтому досрочный выход сокращает проверку, но время всей программы во всех случаях остаётся Θ(n).

T(n) = Θ(n) + O(n) = Θ(n).

## Расчёт памяти

Массив хранит n значений int: 4n байт полезных данных плюс служебные расходы. Общая память под данные — O(n).

Индекс, размер, логический флаг и ссылка на одну из двух строк результата требуют O(1) дополнительной памяти. Строки YES и NO имеют постоянную длину.

## Итог

- Проверка без ввода: лучший случай O(1), худший O(n).
- Вся программа с вводом массива: Θ(n) во всех случаях.
- Общая память под данные: O(n).
- Дополнительная память проверки: O(1).
