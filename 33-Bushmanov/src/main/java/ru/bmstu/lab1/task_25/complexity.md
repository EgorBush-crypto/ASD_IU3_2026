# Задача 25. Сумма элементов

## Обозначения и модель

n — число элементов, 1 < n < 100000. Сравнение, присваивание, обращение по индексу и арифметика над int и long считаются операциями O(1). Чтение и вывод одного числа фиксированного диапазона учитываются как O(1). Ожидание ввода человеком и постоянные расходы JVM не учитываются. O — верхняя оценка, Θ — точный порядок роста.

## Идея решения и корректность

Программа читает n чисел и сразу прибавляет каждое к sum. После i итераций sum равна сумме первых i прочитанных чисел. После n итераций получена сумма всех элементов.

Хранить массив не требуется: каждое число используется один раз. Тип long позволяет избежать переполнения int. При данных ограничениях модуль суммы не превышает 99999 × 2147483648 = 214746217316352, что помещается в long.

## Расчёт времени

1. Чтение n и инициализация sum — O(1).
2. Цикл выполняет ровно n итераций. В каждой читается одно число и выполняется одно прибавление: O(1) на итерацию.
3. Вывод результата — O(1).

T(n) = c1 + c2 × n + c3 = Θ(n).

Досрочного выхода нет, поэтому лучший, средний и худший случаи имеют линейное время Θ(n).

## Расчёт памяти

Массив не создаётся. Хранятся размер n, индекс i и сумма sum. Объём этих данных не зависит от числа элементов.

Общая алгоритмическая память под данные — O(1); дополнительная память — O(1). Входной поток не рассматривается как заранее сохранённый в памяти массив. Фиксированная служебная память чтения чисел не меняет оценку.

## Итог

- Время: O(n), точнее Θ(n).
- Память: O(1).
