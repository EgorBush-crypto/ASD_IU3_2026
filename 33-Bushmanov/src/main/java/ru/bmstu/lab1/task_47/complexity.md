# Задача 47. Поворот матрицы на 90 градусов по часовой стрелке

## Обозначения и модель

n = rows — количество строк исходной матрицы.
m = col — количество столбцов исходной матрицы.
Предполагается n ≥ 1 и m ≥ 1. Матрица содержит n × m элементов типа int.

Обращение к элементу, вычисление индекса, сравнение, чтение и вывод одного числа фиксированного диапазона учитываются как O(1). Время ожидания ввода пользователем и постоянные расходы JVM не учитываются. Θ обозначает точный порядок роста, O — верхнюю оценку.

## Идея решения

Программа сохраняет входную матрицу в a. Для вывода результата она перебирает исходные столбцы слева направо, а внутри каждого столбца — элементы снизу вверх.

Элемент результата в строке i и столбце j берётся из a[n - 1 - j][i]. Поэтому результат имеет m строк и n столбцов и соответствует повороту на 90 градусов по часовой стрелке.

Например, исходная матрица:

    1 2 3
    4 5 6

Результат:

    4 1
    5 2
    6 3

Новая матрица в памяти не создаётся: программа сразу печатает её элементы. Исходный массив a остаётся неизменным.

## Проверка индексов

В цикле вывода i принимает значения от 0 до m - 1. Индекс j принимает значения от 0 до n - 1, поэтому n - 1 - j меняется от n - 1 до 0.

Оба индекса обращения a[n - 1 - j][i] находятся в пределах исходной матрицы. Каждая исходная ячейка выводится ровно один раз.

## Расчёт времени

1. Чтение размеров — O(1).
2. Создание двумерного массива и обнуление его элементов — O(nm + n), то есть O(nm) при m ≥ 1.
3. Чтение матрицы: внешний цикл выполняет n итераций, внутренний — m итераций на каждую внешнюю. Всего n × m чтений, время Θ(nm).
4. Вывод повёрнутой матрицы: внешний цикл выполняет m итераций, внутренний — n. Всего m × n обращений к элементам и выводов чисел, время Θ(nm).
5. После каждой строки результата выводится перевод строки. Таких операций m, поэтому они требуют O(m), что не превышает O(nm) при n ≥ 1.

Два блока вложенных циклов выполняются последовательно. Их времена складываются:

T(n, m) = O(nm) + Θ(nm) + Θ(nm) + O(m) = Θ(nm).

Всего в явных внутренних циклах выполняется 2nm итераций: nm при вводе и nm при выводе. Множитель 2 не влияет на асимптотику. Оценка O(n²m²) неверна: блок вывода не находится внутри блока ввода.

В программе нет досрочного выхода. Лучший, средний и худший случаи — Θ(nm).

Для квадратной матрицы со стороной n, где m = n, время равно Θ(n²). Если обозначить общее число элементов через N = nm, время линейно по N: Θ(N).

## Расчёт памяти

Матрица хранит nm значений int: 4nm байт полезных данных. В Java int[][] также содержит массив ссылок на строки и отдельные массивы строк. Их служебные расходы имеют порядок O(n). Поэтому общая память под данные:

M(n, m) = O(nm + n) = O(nm) при m ≥ 1.

Для обхода используются только размеры и индексы циклов. Новая матрица и рекурсивные вызовы отсутствуют. Дополнительная память самого поворота при выводе — O(1).

Выходной текст отправляется в поток и не накапливается программой в строке или массиве. Память внешнего инструмента, который может сохранять весь вывод (например, тестового помощника), к памяти этого решения не относится.

## Итог

- Время всей программы: O(nm), точнее Θ(nm).
- Общая память с хранением исходной матрицы: O(nm).
- Дополнительная память обхода и вывода повёрнутой матрицы: O(1).
- Для квадратной матрицы: время O(n²), общая память O(n²).
