# Задача 2. Индекс первого вхождения

## Обозначения и модель расчёта

`n` — количество элементов массива, `1 < n < 100000`.
Операции с `int`, сравнение, присваивание и обращение по индексу считаются операциями постоянного времени. Чтение одного числа фиксированного диапазона также учитывается как O(1). Оценивается алгоритм программы без фиксированных расходов JVM; время ожидания ввода пользователем не учитывается.

## Идея решения

Программа считывает массив и искомое число x. Индекс результата сначала равен −1. Массив просматривается слева направо; при первом совпадении сохраняется индекс и выполняется break. Если совпадений нет, результат остаётся равным −1.

## Временная сложность поиска

Если первое совпадение находится на индексе p, выполняется p + 1 сравнение с x. Если совпадений нет, выполняется n сравнений.

- Лучший случай: x находится на индексе 0 — одно сравнение, Θ(1).
- Худший случай: x отсутствует или впервые встречается последним — n сравнений, Θ(n).
- При условии, что элемент присутствует и позиция первого совпадения равновероятна, среднее число сравнений равно (1 + 2 + ... + n) / n = (n + 1) / 2, то есть Θ(n). Без предположений о распределении входов средний случай отдельно не определяется.

## Временная сложность всей программы

1. Создание и инициализация массива — O(n).
2. Чтение всех n элементов — Θ(n).
3. Чтение x и инициализация результата — O(1).
4. Поиск — от Θ(1) до Θ(n).
5. Вывод индекса — O(1).

До начала поиска программа всегда считывает весь массив. Поэтому даже при совпадении с первым элементом общее время — Θ(n).

T(n) = Θ(n) + O(n) = Θ(n).

Последовательные этапы складываются; вложенных циклов здесь нет.

## Пространственная сложность

Исходный массив содержит n значений int: 4n байт полезных данных плюс служебные расходы. Общая память под данные — O(n).

Переменные `n`, `x`, `xindex`, `i` требуют постоянного объёма. Дополнительная память поиска без учёта массива — O(1).

## Итог

- Поиск: лучший случай O(1), худший O(n).
- Время всей программы с чтением массива: Θ(n) во всех случаях.
- Общая память под данные: O(n).
- Дополнительная память поиска: O(1).
