## 4. Основные идеи решений

1. **Задача 1:** минимум и максимум инициализируются первым элементом. При последовательном просмотре массива обновляются найденные значения.
2. **Задача 2:** массив просматривается слева направо до первого совпадения с числом x. Если совпадений нет, выводится −1.
3. **Задача 3:** каждый элемент сравнивается с x; число совпадений накапливается в счётчике.
4. **Задача 5:** суммируются элементы с индексами 0, 2, 4 и далее. Сумма хранится в long.
5. **Задача 9:** сравниваются соседние элементы. При первом нарушении неубывания проверка прекращается. Равные значения допускаются.
6. **Задача 15:** соседние элементы меняются местами при нарушении порядка. Каждый обмен учитывается счётчиком long. Проход без обменов завершает сортировку.
7. **Задача 25:** числа суммируются непосредственно при чтении. Хранение массива не требуется; сумма имеет тип long.
8. **Задача 28:** массив сортируется через Arrays.sort. Медиана определяется по одному или двум центральным элементам. Для чётной длины сложение выполняется в long, а деление — в double.
9. **Задача 39:** величина сдвига приводится к остатку по длине массива. Элементы записываются во вспомогательный массив на позиции (i + step) % n и копируются обратно.
10. **Задача 47:** исходные столбцы выводятся слева направо, а элементы каждого столбца — снизу вверх. Это формирует поворот по часовой стрелке без создания второй матрицы.

## 5. Сводная оценка сложности

Здесь n — длина одномерного массива; для задачи 47 n и m — число строк и столбцов. Время включает ввод и вывод. Общая память учитывает исходный массив, дополнительная — память алгоритма сверх него. Операции над числами фиксированного диапазона считаются O(1).

| Задача | Время всей программы | Общая память под данные | Дополнительная память алгоритма |
|---|---|---|---|
| 1 | O(n) | O(n) | O(1) |
| 2 | O(n) | O(n) | O(1) |
| 3 | O(n) | O(n) | O(1) |
| 5 | O(n) | O(n) | O(1) |
| 9 | O(n) | O(n) | O(1) |
| 15 | Лучшее O(n), худшее O(n²) | O(n) | O(1) |
| 25 | O(n) | O(1) | O(1) |
| 28 | O(n log n), верхняя оценка | O(n) | O(n) в худшем случае с учётом сортировки OpenJDK 25 |
| 39 | O(n) | O(n) | O(n) при ненулевом сдвиге; O(1) при нулевом |
| 47 | O(nm) | O(nm) | O(1) |

В задачах 2 и 9 сама проверка может завершиться за O(1), но полное чтение массива сохраняет линейное время всей программы. В задаче 39 при нулевом нормализованном сдвиге метод завершается сразу, однако ввод и вывод остаются линейными.

В задаче 28 вычисление медианы уже отсортированного массива требует O(1) времени и памяти. Основные затраты связаны с библиотечной сортировкой. Оценка её дополнительной памяти относится к реализации OpenJDK 25: при слиянии упорядоченных участков возможно создание вспомогательного массива. Подробности приведены в расчёте этой задачи.

## 6. Тестирование

Для каждой задачи подготовлен отдельный класс MainTest. Общий [ConsoleTestSupport](src/test/java/ru/bmstu/lab1/ConsoleTestSupport.java) подставляет входные данные в System.in, перехватывает System.out и сравнивает полученный текст с ожидаемым ответом. После запуска исходные потоки восстанавливаются.

При сравнении нормализуются переводы строк и удаляются пробелы в конце строк и крайние пустые строки. Числа, регистр букв и внутренние пустые строки проверяются. Тесты используют общие потоки, поэтому должны запускаться последовательно.

| 2 | Отсутствие числа, первое из нескольких совпадений, совпадение в начале и конце |
| 3 | Отсутствие совпадений, совпадение всех элементов, нули, крайние значения int |
| 5 | Различие чётности индекса и значения, отрицательные суммы, компенсация слагаемых, выход суммы за диапазон int |
| 9 | Неубывающий массив, равные элементы, нарушение порядка в начале, середине и конце |
| 15 | Обратный порядок, уже отсортированный массив, повторы, отрицательные значения, точное число обменов |
| 25 | Смешанные знаки, нули, большие суммы, крайние значения int, 99999 элементов |

| 39 | Нулевой сдвиг, сдвиг больше длины, полные обороты, большое k, повторяющиеся элементы |

### Контрольные примеры для ручного запуска

В таблице точка с запятой разделяет строки ввода или вывода; вводить сам символ «;» не нужно.

| Задача | Ввод | Ожидаемый вывод | Что проверяется |
|---|---|---|---|
| 1 | `3; -8 -2 -5` | `-8 -2` | Минимум и максимум среди отрицательных чисел |
| 2 | `4; 4 2 4 1; 4` | `0` | Возвращается первое совпадение |
| 3 | `4; 4 2 4 4; 4` | `3` | Подсчёт повторов |
| 5 | `3; 2000000000 0 2000000000` | `4000000000` | Сумма выходит за диапазон int |
| 9 | `4; 1 1 2 2` | `YES` | Равные соседи допускаются |
| 15 | `3; 3 2 1` | `1 2 3; 3` | Сортировка и количество обменов |
| 25 | `5; 3 -2 7 0 4` | `12` | Сумма чисел разных знаков |
| 28 | `4; 4 1 3 2` | `2.5` | Дробная медиана после сортировки |
| 39 | `5; 1 2 3 4 5; 7` | `4 5 1 2 3` | Сдвиг k больше длины |
| 47 | `2 3; 1 2 3; 4 5 6` | `4 1; 5 2; 6 3` | Поворот прямоугольной матрицы |

## 8. Вывод

В работе реализованы десять алгоритмов обработки массивов и матриц. Для решений подготовлены автоматические тесты и расчёты временной и пространственной сложности.

Большинство задач решается одним или несколькими последовательными проходами и имеет линейную сложность по числу элементов. Пузырьковая сортировка в худшем случае требует O(n²) времени, а решение поиска медианы через сортировку — O(n log n). Для матрицы время зависит от общего числа элементов и равно O(nm).

При выполнении работы рассмотрены досрочное завершение циклов, выбор числовых типов для предотвращения переполнения, различие общей и дополнительной памяти, а также влияние формата вывода на результаты автоматической проверки. Использование тестов позволяет проверять обычные и граничные случаи после изменения программ.
